# Supaterm

This file is a stable discovery stub. Load the guide bundled with the installed `sp` version before running Supaterm commands:

```bash
sp skills get core
```

Load the complete command references when needed:

```bash
sp skills get core --full
```

Load the coding-agent workflow before launching or prompting a coding agent:

```bash
sp skills get coding-agents
```

List every guide available in the installed version:

```bash
sp skills list
```
